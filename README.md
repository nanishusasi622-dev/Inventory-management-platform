# Inventory Management Platform

A responsive web-based inventory management project for adding, editing, deleting, searching and monitoring products.

## Technologies
- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## Features
- Dashboard with total products, total stock, low-stock count and inventory value
- Add, edit and delete products
- Search by product name or category
- Filter by category
- Automatic stock status
- Data persistence using LocalStorage
- Responsive design

## Run in VS Code
1. Extract the ZIP file.
2. Open the folder in Visual Studio Code.
3. Open `index.html`.
4. Use Live Server or open the HTML file directly in a browser.
